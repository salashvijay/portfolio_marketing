# Vihsm company portfolio

Public site for `vihsmai.com`. Company work only: APIs, apps, websites, and hosting. It is not a personal résumé.

## Before you publish

1. Create the mailbox `hello@vihsmai.com`, or change `email` in `site.js`.
2. Put the WhatsApp number in `site.js` as country code plus number, for example `9198XXXXXXXX`. Until then the WhatsApp button stays hidden.
3. Add the Tanuku hospital link only after that client has agreed in writing.

## Run locally

Open `index.html` in a browser, or from this folder:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Coolify

This folder is its own site. Point a Coolify application at this repo, Dockerfile build, port 80. Attach `vihsmai.com` and `www.vihsmai.com`. Do not deploy the marketing-notes repo as this site.
